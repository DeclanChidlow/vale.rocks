title: Identifying Asian Scripts
tags: [language]
---

A far from perfect little table, but one that hopefully gets the point across and works as a reference. Scripts ≠ languages, with many scripts being used by many languages.

<figure>
<div class="table-wrapper">

| Script             | Indicators                                                                                 | Example                                       |
| :----------------- | :----------------------------------------------------------------------------------------- | :-------------------------------------------- |
| Chinese            | Dense, complex, and boxy.                                                                  | <span lang="zh-Hans">这里的门在哪？</span>    |
| Japanese           | Mixes dense Chinese-style characters with simpler curved kana symbols.                     | <span lang="ja">明日も仕事です。</span>       |
| Korean             | Highly geometric; lots of circles and straight lines.                                      | <span lang="ko">어디로 가야 하죠?</span>      |
| Thai               | Tall, narrow letters with tiny loops/circles at the start of strokes.                      | <span lang="th">ตรงนี้มีอะไรขาย?</span>       |
| Khmer              | Similar to Thai but busier with wavy, ornate tops and more horizontal connection.          | <span lang="km">ខ្ញុំមិនយល់ទេ។</span>         |
| Burmese            | Extremely round; looks like a collection of interlocking circles. Very few straight lines. | <span lang="my">ဘယ်လောက်ကြာမလဲ?</span>        |
| Devanagari (Hindi) | Distinct horizontal bar connecting letters at the top.                                     | <span lang="hi">बस कब आएगी?</span>            |
| Bengali            | Has a top bar like Hindi, although segmented. Letters are more triangular/pointy.          | <span lang="bn">আমি এখনই আসছি।</span>         |
| Tamil              | No top bar. Curvy with blocky loops and square shapes.                                     | <span lang="ta">எனக்கு புரியவில்லை.</span>    |
| Sinhala            | Very curvy and ornate with spiral-like curves.                                             | <span lang="si">මට ඒක දෙන්න.</span>           |
| Tibetan            | Top-heavy characters with a horizontal line and long, sharp vertical descenders.           | <span lang="bo">ག་རེ་བྱེད་ཀྱི་ཡོད།</span>     |
| Vietnamese         | Latin alphabet with lots of diacritics (often multiple on the same character).             | <span lang="vi">Cửa hàng đóng cửa rồi.</span> |
| Arabic             | Flowing connected cursive written right-to-left; many dots above/below letters.            | <span lang="ar">هل هذا صحيح؟</span>           |
| Cyrillic           | Similar to Latin alphabet but with distinctive letters including Ж, Д, Ы, Ф.               | <span lang="ru">Как это работает?</span>      |
| Lao                | Similar to Thai but rounder and less vertically tall.                                      | <span lang="lo">ເຮັດຫຍັງຢູ່?</span>           |
| Gurmukhi           | Straight top line like Devanagari but with more open rounded forms.                        | <span lang="pa">ਮੈਨੂੰ ਪਤਾ ਨਹੀਂ।</span>        |
| Telugu             | Very round with many hanging curves and circular shapes.                                   | <span lang="te">నాకు అర్థం కాలేదు.</span>     |
| Kannada            | Rounded like Telugu but more compact and angular.                                          | <span lang="kn">ಇದು ಎಲ್ಲಿ ಸಿಗುತ್ತದೆ?</span>   |
| Hebrew             | Blocky right-to-left script with compact letters and few curves.                           | <span lang="he">מה השעה עכשיו?</span>         |

</div>
</figure>
